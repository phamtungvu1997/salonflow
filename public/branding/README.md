# SalonFlow brand assets

Approved masters were provided by the Owner (gradient S symbol + dark-purple wordmark).

| File | Use |
|---|---|
| `salonflow-symbol.png` | Collapsed sidebar, favicon source, lockup |
| `salonflow-wordmark.png` | Light surfaces / lockup (approved dark purple) |
| `salonflow-wordmark-on-dark.png` | Dark sidebar only — same letterforms, light ink for contrast |
| `salonflow-lockup.png` | Login lockup (symbol + approved dark wordmark) |
| `salonflow-favicon.png` / `-48` / apple-touch | Browser icons |
| `source-masters/` | Unmodified copies of uploaded JPG masters |

**SVG:** Not provided. The ribbon mark’s soft gradients and depth cannot be faithfully reconstructed as pure vectors from the raster masters without redesigning the mark.

**Regenerate:** `python scripts/prepare-branding-assets.py` (requires Pillow; does not alter the uploaded source files under Cursor assets).
